# Jump & Learn

A competitive 2.5D/3D jump-and-answer gamified e-learning mobile & web application built with **Flutter**, **Flame**, and **Google Firebase**.

## Tech Stack
- **Language**: Dart
- **Framework**: Flutter (Android, iOS, Web)
- **Game Engine**: Flame (2.5D Isometric Projection + Parabolic Physics)
- **Backend**: Firebase Auth, Cloud Firestore, Firebase Realtime Database
- **State & Routing**: Riverpod + GoRouter
